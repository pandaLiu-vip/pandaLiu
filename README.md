## 本地预览

用浏览器打开 `index.html` 即可查看，无需安装依赖或执行构建。也可以在仓库目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000>。字体来自 Google Fonts；无法连接时会使用本地备用字体，内容和功能仍可使用。

## 发布到 GitHub Pages

仓库已包含自动部署工作流 [pages.yml](.github/workflows/pages.yml)。首次发布：

1. 在 GitHub 仓库打开 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 将本地文件提交并推送到 `main`，工作流会自动部署；也可在 **Actions → Deploy personal AI archive → Run workflow** 手动触发。
4. 等待工作流成功，再打开 <https://pandaliu-vip.github.io/pandaLiu/>。

Pages 已配置为使用 GitHub Actions；后续推送到 `main` 会自动更新网站，部署结果可在仓库 Actions 中查看。
